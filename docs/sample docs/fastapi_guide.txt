FastAPI Framework FAQ

Q: What is FastAPI?
FastAPI is a modern, high-performance Python web framework for building APIs, based on Python type hints. It is built on Starlette for web handling and Pydantic for data validation. FastAPI automatically generates interactive API documentation (Swagger UI at /docs and ReDoc at /redoc) from your code.

Q: How do you define a Pydantic model in FastAPI?
Define models by inheriting from BaseModel: from pydantic import BaseModel; class Item(BaseModel): name: str; price: float; in_stock: bool = True. FastAPI uses these for request body validation, response serialization, and automatic docs. Pydantic validates input data and raises 422 Unprocessable Entity errors automatically on invalid input.

Q: What is dependency injection in FastAPI?
FastAPI has a built-in dependency injection system using Depends(). Define a function that provides shared resources (database sessions, auth checks) and inject it with: def my_route(db: Session = Depends(get_db)). Dependencies can have their own dependencies (sub-dependencies). Useful for database connections, authentication, and shared configuration.

Q: What is the FastAPI lifespan event?
Lifespan is a context manager that runs code on startup and shutdown. Use it to load ML models, connect to databases, or initialize caches once at startup instead of on every request. Pattern: @asynccontextmanager async def lifespan(app): [startup code]; yield; [shutdown code]. Pass to FastAPI(lifespan=lifespan).

Q: How do you add CORS to FastAPI?
Add CORSMiddleware: from fastapi.middleware.cors import CORSMiddleware; app.add_middleware(CORSMiddleware, allow_origins=["http://localhost:3000"], allow_methods=["*"], allow_headers=["*"]). For development you can use allow_origins=["*"] but for production specify exact origins for security.

Q: How do you write tests for FastAPI?
Use TestClient from fastapi.testclient: client = TestClient(app). Then write pytest tests: def test_create_user(): response = client.post("/users/", json={"name": "Alice"}); assert response.status_code == 201. TestClient wraps requests library, making tests synchronous. For async tests use httpx.AsyncClient with pytest-asyncio.

Q: What are path, query, and body parameters in FastAPI?
Path parameters are in the URL: /users/{user_id}. Query parameters are in the URL after ?: /users?skip=0&limit=10. Body parameters come in the request body as JSON, defined by a Pydantic model. FastAPI auto-detects: simple types become query params, Pydantic models become body params, path template variables become path params.
