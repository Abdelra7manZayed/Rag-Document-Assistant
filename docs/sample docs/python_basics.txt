Python Programming Fundamentals FAQ

Q: What is Python?
Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum in 1991. It emphasizes code readability and uses significant whitespace. Python supports multiple programming paradigms including procedural, object-oriented, and functional programming.

Q: What are Python virtual environments and why use them?
A virtual environment is an isolated Python environment that allows you to install packages for a specific project without affecting the system Python or other projects. Create one with: python -m venv .venv and activate it with .venv\Scripts\activate on Windows or source .venv/bin/activate on Linux/macOS. Always use virtual environments to avoid dependency conflicts between projects.

Q: What is the difference between list and tuple in Python?
Lists are mutable (can be changed after creation) and use square brackets: my_list = [1, 2, 3]. Tuples are immutable (cannot be changed) and use parentheses: my_tuple = (1, 2, 3). Tuples are faster and use less memory, making them suitable for fixed data. Lists are used for collections that may need modification.

Q: How does Python manage memory?
Python uses automatic memory management via reference counting and a cyclic garbage collector. When an object's reference count drops to zero, it is immediately freed. The garbage collector handles circular references. Developers rarely need to manage memory manually, but tools like tracemalloc can be used to profile memory usage.

Q: What are Python decorators?
Decorators are a design pattern that allows adding new functionality to an existing function without modifying it. They use the @symbol syntax. Example: @staticmethod, @classmethod, @property, @app.route in Flask. You can write custom decorators by defining a function that takes another function as argument and returns a wrapper function.

Q: What is PEP 8?
PEP 8 is the official Python style guide. Key rules: use 4 spaces for indentation (never tabs), limit lines to 79 characters, use snake_case for variables and functions, PascalCase for classes, UPPER_CASE for constants, two blank lines between top-level definitions, and one blank line between methods.

Q: What are Python type hints?
Type hints (introduced in Python 3.5) allow you to annotate variables and function signatures with types. Example: def greet(name: str) -> str: return f"Hello, {name}". They do not enforce types at runtime but improve code readability and enable static analysis tools like mypy to catch type errors before running code.

Q: What is list comprehension?
List comprehension is a concise way to create lists. Syntax: [expression for item in iterable if condition]. Example: squares = [x**2 for x in range(10) if x % 2 == 0]. It is generally faster and more readable than equivalent for loops for simple transformations and filters.
